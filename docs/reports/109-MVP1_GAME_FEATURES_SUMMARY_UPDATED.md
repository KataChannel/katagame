## 🏘️ PROVINCE UPGRADE SYSTEM (NEW)

### 3 Upgrade Dimensions Per Province

Each province has **3 independent upgrade tracks**:

#### 1️⃣ FARMER UPGRADE (農民 - Nông Dân)
- **Max Level**: 20
- **Purpose**: Increase population and basic resource generation
- **Benefits per Level**:
  - +5% resource generation
  - +10 population capacity
  - Unlock new building slots
- **Cost**: Gold + Rice (increases with level)
- **MVP1 Goal**: Reach Farmer Lv 10 (example objective)

#### 2️⃣ RESOURCE UPGRADE (資源 - Tài Nguyên)
- **Max Level**: 10
- **Purpose**: Enhance specific resource production
- **MVP1 Choice**: Gold Production
- **Benefits per Level**:
  - +20% Gold generation
  - +10% Rice generation (synergy)
  - Unlock advanced processing
- **Cost**: Gold + Wood (requires spending resources)
- **MVP1 Goal**: Reach Resource Lv 5 (example objective)

#### 3️⃣ DEVELOPMENT UPGRADE (發展 - Phát Triển)
- **Max Level**: 15
- **Purpose**: Province overall development & infrastructure
- **Benefits per Level**:
  - +3% all resources in province
  - +5% population happiness
  - Unlock special features
  - Faster building construction (-2% time)
- **Cost**: All resources combined
- **MVP1 Goal**: Reach Development Lv 5 (example objective)

### Hidden Milestone System (NEW)

At certain levels, hidden bonuses activate:

```
HIDDEN MILESTONE TRIGGERS
═════════════════════════════════════════════

Farmer Level 5:
├─ Passive Bonus: +2% resources per harvest (permanent)
└─ Notification: "Nông Dân Thành Thạo!" (Skilled Farmer!)

Resource Level 3:
├─ Synergy Bonus: +3% Rice when harvesting Gold
└─ Notification: "Cây Lúa Khỏe Mạnh!" (Healthy Rice!)

Resource Level 8:
├─ Active Bonus: 1x per day, random multiplier (x2/x3/x5) for 1 hour
├─ Duration: 1 hour duration, 1 day cooldown
└─ Notification: "Tài Nguyên Phù Trợ! ×3 trong 1 giờ!"
   (Land Blesses! ×3 for 1 hour!)

Development Level 5:
├─ Infrastructure Bonus: -10% building construction time (permanent)
└─ Notification: "Thành Phố Phát Triển!" (City Thrives!)
```

- Learning quiz (1/3): ×2 multiplier

**Daily Engagement**:
```
Morning Routine (15 min):
├─ Login → Collect resources

Learning Value: +1 historical story per day
```

**Scoring**:
