## 🆕 NEW GAME FEATURES (MVP 3 Additions)

### 1. ✅ Complete Vietnam Map (63 Provinces)
**Mô tả**: Expand from 9 to 63 provinces (all of Vietnam)  

**Map Regions**:
```
Northern Region (18 provinces):
├─ Existing: Hà Nội, Nghệ An, Quảng Ninh, Hà Giang, etc.
├─ New: Yên Bái, Phú Thọ, Bắc Giang, Thái Nguyên, etc.
└─ Features: Mountains, resources, militia defense

Central Region (20 provinces):
├─ Existing: Nghệ An, Hà Tĩnh
├─ New: Thanh Hóa, Hồng Lĩnh, Huế, Da Nẵng, etc.
└─ Features: Coastal trade, agriculture, diverse economy

Southern Region (25 provinces):
├─ New: Cần Thơ, Hồ Chí Minh, Bến Tre, Vũng Tàu, etc.
├─ New: Sóc Trăng, Cà Mau, An Giang, Kiên Giang, etc.
└─ Features: Mekong delta, tropical, merchant powers
```

**Province Progression**:
```
MVP1: 3 provinces  (beginner, ~10 hours)
MVP2: 9 provinces  (intermediate, ~40 hours)
MVP3: 63 provinces (advanced, ~200+ hours)

New players start at Hà Nội
Unlock new provinces by:
├─ Reaching player level milestones
├─ Defeating provinces in sequence
├─ Discovering through exploration
└─ Trading/conquering through guilds
```

**Each Province Includes**:
- Unique historical narrative (3-5 quests)
- Province-specific resources (3-5 types)
- Regional building types (unique to region)
- Economic specialization (trade route value)
- Geographical bonuses (mountain/coastal/river)
- Historical figures (heroes to recruit)
- Strategic military value (territory control)

### 2. ✅ Guild Wars System (NEW!)
**Tên gọi**: "Guild Conquest" / "Territory Wars"  
**Mô tả**: Guild vs Guild competitive battles for territory  

**Guild System Overview**:
```
┌────────────────────────────────────────────┐
│ GUILD CREATION                             │
├────────────────────────────────────────────┤
│ Cost: 99,000 VND (one-time)                │
│ Max members: 50 players                    │
│ Guild levels: 1-30 (upgradeable)          │
│ Guild perks: +5% resource per level       │
│ Guild bank: Shared storage for members    │
└────────────────────────────────────────────┘
```

**Guild War Mechanics**:
```
War Cost: 19,000 VND per attack (entry fee)
     ↓
Challenge enemy guild → 48-hour declaration
     ↓
War period: 5 days of battles
     ↓
Members battle → Earn war points
     ↓
Winner: Most points after 5 days
     ↓
Rewards: 
├─ Gold for guild treasury
├─ Territory capture (1-3 provinces)
├─ War cosmetics (exclusive skins)
└─ Prestige points (guild ranking)
```

**Guild Warfare Types**:
1. **Guild War** (Weekly)
   - 5-day battle period
   - Guild vs Guild
   - Territory control

2. **Guild Dungeon** (Cooperative)
   - PvE against boss
   - All members fight together
   - Shared rewards

3. **Guild Tournament** (Monthly)
   - 16-guild bracket
   - Single elimination
   - Grand prize: 1 million gems

**Expected Revenue (MVP3)**:
- War entry fees: 19K per attack
- Active guilds: 1,000+ guilds
- Wars per week: 5 per guild avg
- 1,000 guilds × 5 wars × 19K = 95M VND/week
- **~380M VND/month**
- **% of MVP3 revenue: 10%**

### 3. ✅ Marketplace System (NEW!)
**Tên gọi**: "Trading Post" / "Player Marketplace"  
**Mô tả**: Player-to-player trading of resources & items  

**Marketplace Features**:
```
┌─────────────────────────────────────────┐
│ WHAT CAN BE TRADED                      │
├─────────────────────────────────────────┤
│ ✓ Resources (food, wood, stone, etc.)   │
│ ✓ Cosmetics (skins, emotes, titles)     │
│ ✓ Consumables (potions, buffs)          │
│ ✓ Heroes (character trades)             │
│ ✓ Equipment (weapons, armor)            │
│ ✗ Premium Pass (cannot trade)           │
│ ✗ Gems (cannot trade directly)          │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ MARKETPLACE FEES                        │
├─────────────────────────────────────────┤
│ 2% transaction fee (goes to game)        │
│ Example: Sell 100K gold → 98K received  │
│ Protection: Player can't lose resources │
│ System: Smart contract escrow           │
└─────────────────────────────────────────┘
```

**Marketplace Interface**:
```
Browse listings → Search items
     ↓
View price history (graph)
     ↓
Place buy order / Wait for seller
     ↓
Transaction completes (2% fee charged)
     ↓
Items delivered to inventory
     ↓
Money transferred to seller wallet
```

**Marketplace Supply/Demand**:
```
Resource shortages → Prices rise
          ↓
Players sell extra → Supply increases
          ↓
Prices stabilize → Economy balance
          ↓
New events → Supply shock → Speculation
          ↓
Game economy becomes self-regulating
```

**Expected Revenue (MVP3)**:
- Transaction volume: 500M VND/month (est)
- 2% fees: 10M VND/month from fees alone
- Plus: Indirect (keeps players engaged longer)
- **~50M VND/month (direct + indirect)**
- **% of MVP3 revenue: 5%**

### 4. ✅ Leaderboard System with Cosmetics (NEW!)
**Tên gọi**: "Rankings" / "Seasonal Leaderboards"  
**Mô tả**: Competitive rankings with exclusive cosmetic rewards  

**Leaderboard Types**:
```
1. POWER LEADERBOARD
├─ Based: Total military power
├─ Ranking: Top 1,000 players
├─ Refresh: Weekly
└─ Rewards: Top 100 get cosmetics

2. CONQUEST LEADERBOARD
├─ Based: Provinces controlled
├─ Ranking: Top 1,000 players
├─ Refresh: Weekly
└─ Rewards: Top 100 get titles

3. WEALTH LEADERBOARD
├─ Based: Total resources + marketplace value
├─ Ranking: Top 1,000 players
├─ Refresh: Daily
└─ Rewards: Top 100 get cosmetics

4. GUILD LEADERBOARD
├─ Based: Guild war points + territory
├─ Ranking: Top 50 guilds
├─ Refresh: Weekly
└─ Rewards: Guild cosmetics for all members

5. SEASONAL PASS LEADERBOARD
├─ Based: Battle Pass tier progress
├─ Ranking: Top 100 players
├─ Refresh: Daily
└─ Rewards: Exclusive seasonal cosmetics
```

**Leaderboard Cosmetics** (Exclusive):
```
Tier 1 (Rank 1-10):     Legendary title + hero skin
Tier 2 (Rank 11-50):    Epic title + weapon skin
Tier 3 (Rank 51-100):   Rare title + cosmetic
Tier 4 (Rank 101-1000): Common title + badge

Cosmetics are:
✓ Only obtainable through leaderboards
✓ Reset each season (keeps fresh)
✓ Status symbol (shows accomplishment)
✓ Encourages competitive play
```

**Expected Revenue (MVP3)**:
- Drives competitive spending (want rank 100 cosmetics)
- Increased Premium Pass sales (faster leveling)
- Increased gem purchases (rush to rank up)
- **~200M VND/month (indirect boost)**
- **% of MVP3 revenue: 5%**
