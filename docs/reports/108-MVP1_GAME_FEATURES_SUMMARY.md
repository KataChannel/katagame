## 📋 MVP 1 OVERVIEW - NEW VISION

**Tên gọi**: "Khởi Nguồn Đất Việt" (Foundations of Vietnam)  
**Mô tả**: Educational strategy game + Historical stories + Sustainable farming  
**Timeline**: 8 tuần (Nov 1 - Dec 31, 2025)  
**Số người chơi mục tiêu**: 50,000 - 100,000 DAU (Daily Active Users)  
**Loại game**: Educational History Game + Click & Auto-farming + Strategy

### Project Goals
1. **📚 Educational**: Teach Vietnamese history, geography, culture
2. **💰 Social Impact**: Support national programs, generate fundraising opportunities
3. **🎮 Gameplay**: Engage players through sustainable earning mechanics
4. **🌍 Cultural**: Build national pride and appreciation for Vietnamese heritage

## 🎮 CORE GAME FEATURES (NON-MONETIZATION)

### 1. ✅ Farming & Resource Management System
**Mô tả**: Click & Auto-farming mechanics  
**Chi tiết**:
- ✓ Click resources (wood, stone, food, population)
- ✓ Auto-harvest every 30 seconds
- ✓ Resource generation based on province level
- ✓ Resource limits (storage capacity)
- ✓ Auto-save every 30 seconds

**Gameplay Flow**:
```
Players click → Resources earned → Storage fills up
     ↓
Reach storage limit → Need upgrades/expansions
     ↓
Spend resources → Unlock new features
```

### 2. ✅ Province System (3 Provinces)
**Mô tả**: 3 playable provinces in MVP 1  
**Provinces**:
1. **Hà Nội** - Capital region
   - Starting province
   - Basic economy
   - Introduction story
   
2. **Nghệ An** - Central region  
   - Intermediate difficulty
   - More resources available
   - Some restrictions
   
3. **Quảng Ninh** - Northern region
   - Advanced difficulty
   - Rare resources
   - Challenging mechanics

**Per Province Features**:
- Unique visual theme (Tinh Tế Design)
- Different resource types available
- Province-specific quests/challenges
- Territory expansion mechanics

### 3. ✅ Battle/Combat System (Basic)
**Mô tả**: Turn-based combat for MVP 1  
**Cơ chế**:
- ✓ Auto-attack mechanic (no manual control in MVP1)
- ✓ Enemy spawning in each province
- ✓ Victory = loot/resources
- ✓ Defeat = nothing lost (but time wasted)
- ✓ Battle duration: 30 seconds - 3 minutes
- ✓ Simple victory conditions

**Combat Flow**:
```
Player initiates battle → Auto-attack happens
       ↓
Enemy health 0 → Victory! Receive rewards
       ↓
OR Player walks away → Battle ends (can retry)
```

### 4. ✅ Building/Structures System
**Mô tả**: Construct buildings to boost economy  
**Building Types**:
- **Farms** - Produce food resources
- **Markets** - Trade and commerce
- **Barracks** - Military buildings
- **Temples** - Special bonuses
- **Storage** - Increase resource limits
- **Workplaces** - Population management

**Building Mechanics**:
```
Build cost: X resources + Y time
       ↓
Construction countdown (1 min - 24 hours)
       ↓
Complete → Gain bonuses to resources/army
       ↓
Upgrade → Increase effectiveness
```

### 5. ✅ Population & Army System
**Mô tả**: Manage population and military units  
**Population**:
- ✓ Starting population: 100
- ✓ Max population grows with buildings
- ✓ Population generates resources
- ✓ Population can be assigned to army

**Army Units** (Basic):
- Soldiers (basic unit)
- Archers (range unit)
- Cavalry (fast unit)
- Limited unit types in MVP1

**Mechanics**:
```
Population generated from buildings
       ↓
Assign to army → Military power increases
       ↓
Use army in battles/exploration
```

### 6. ✅ Hero/Character System
**Mô tả**: Recruit and manage heroes  
**Hero Mechanics**:
- ✓ Starter hero given at game start
- ✓ Additional heroes can be recruited (costs resources)
- ✓ Hero stats: Attack, Defense, HP, Level
- ✓ Heroes level up through battles
- ✓ Hero equipment system (basic)
- ✓ Hero rarity: Common, Rare, Legendary (future)

**MVP1 Heroes**:
- Limited hero roster (5-10 heroes)
- Simple stat progression
- No complex abilities yet

### 7. ✅ Tutorial System (6-Step)
**Mô tả**: Onboarding new players  
**Tutorial Steps**:
1. **Welcome** - Game intro & theme
2. **Farming Basics** - Learn click/auto-harvest
3. **Resources** - Understand resource types
4. **Building** - Construct first building
5. **Combat** - Fight first enemy
6. **Completion** - Claim starter rewards

**Tutorial Features**:
- Skip option (for experienced players)
- Hint system (if player stuck)
- Reward for completion (bonus resources)

### 8. ✅ Progression & Leveling System
**Mô tả**: Player & province level progression  
**Player Level**:
- ✓ Increases with province milestones
- ✓ Unlocks new features/areas
- ✓ Level 1-50 in MVP1

**Province Level**:
- ✓ Upgradeable through building/expansion
- ✓ Higher level = more resources
- ✓ Maximum level 10 per province in MVP1

**Level Progression**:
```
Complete milestones → XP earned
       ↓
Reach XP threshold → Level up!
       ↓
Unlock new buildings/heroes/areas
```

### 9. ✅ Auto-Save System
**Mô tả**: Automatic game save every 30 seconds  
**Features**:
- ✓ Save interval: 30 seconds
- ✓ Prevents progress loss
- ✓ Supports app crash recovery
- ✓ Cloud sync with backend
- ✓ Manual save option

### Revenue Stream 3: Daily Deals / Flash Sales
**Tên gọi**: "Limited Daily Offers"  
**Mô tả**: Time-limited discounts on gems & items  

**Daily Deal Format**:
```
┌─────────────────────────────────────────────────┐
│ DAILY DEAL (Different each day)                 │
├─────────────────────────────────────────────────┤
│ ⏰ Limited time: 6 AM - 11:59 PM (18 hours)     │
│                                                 │
│ Example Day 1: "Gem Rush"                       │
│ └─ 200 Gems for 30,000 (was 50,000) -40% OFF   │
│                                                 │
│ Example Day 2: "Hero Skin Special"             │
│ └─ Legendary skin for 49,900 (was 99,900)     │
│                                                 │
│ Example Day 3: "Resource Boost"                │
│ └─ 100,000 food for 19,900 (was 50,000)       │
│                                                 │
│ FOMO Mechanics:                                │
│ ✓ "24 hours left!" countdown                   │
│ ✓ Different deal each day                      │
│ ✓ Can't repeat old deals                       │
│ ✓ "X people already bought today" social proof │
└─────────────────────────────────────────────────┘
```

**Flash Sale Types**:
1. **Gem Sales** (40-50% discount) - Most effective
2. **Skin Sales** (20-30% discount)  
3. **Resource Bundles** (25-35% discount)
4. **Combo Deals** (multiple items)

**Why Daily Deals Work**:
- Creates **daily login habit** (check what's new)
- **FOMO** (Fear of Missing Out) drives impulse purchases
- **Scarcity** (limited time) increases urgency
- **Discount psychology** (people love "deals")

**Expected Revenue (MVP1)**:
- Average daily deal: 2-3 sales per 100 DAU
- Average deal price: 35,000 VND
- 10,000 DAU × 2.5% = 250 sales/day
- 250 × 35K = 8.75M VND/day
- **~260M VND/month expected**
- **% of MVP1 revenue: ~10%**

## 🎮 GAME MECHANICS SUMMARY

### Gameplay Loop (Daily)

```
DAILY PLAYER ROUTINE:

Morning Login
    ↓
├─ Collect auto-harvest resources (30s regeneration)
├─ Check daily deal (limited offer)
├─ Send hero to battle
├─ Upgrade building
└─ Claim rewards
    ↓
Mid-day Play Session
    ├─ Click resources intensively
    ├─ Start construction projects
    └─ Engage in battles
    ↓
Evening Login
    ├─ Collect finished constructions
    ├─ Complete daily quests
    └─ Check Premium Pass benefits
    ↓
Before Sleep
    ├─ Use remaining energy/stamina
    ├─ Place army defending
    └─ End session
    ↓
Auto-collection via push notification (after 8 hours)
```

### Progression Flow

```
NEW PLAYER → TUTORIAL → FIRST PROVINCE → EXPAND → NEW PROVINCES
   Week 1        3 days        Day 4-14       Week 3      Week 4+

Unlock → Battles → Heroes → Advanced Buildings → Guilds (MVP2)
```

## 💡 WHY MVP 1 FEATURES WORK

### 1. **Educational Value**
- Learn Vietnamese history while playing
- Appeals to parents & schools
- Sustainable positioning (not "just a game")

### 2. **Free-to-Play (NO Pay-to-Win)**
- Cosmetics only (Premium Pass gives convenience, not power)
- Premium Pass = faster XP (shortcut, not unfair advantage)
- Free players can still win battles
- Retention = premium over monetization

### 3. **Multiple Revenue Streams**
- Premium Pass (recurring)
- Shop (impulse)
- Daily Deals (FOMO)
- Not dependent on single income source

### 4. **Viral Mechanics**
- Achievements (share with friends)
- Profiles (show progress)
- Cosmetics (social display)
- Leaderboards (competitive comparison)

### 5. **Psychological Pricing**
- 99K/299K/999K (ends in 9, feels cheaper)
- Gem bundles with bonuses (better value = feels smart)
- Daily deals (FOMO creates urgency)
