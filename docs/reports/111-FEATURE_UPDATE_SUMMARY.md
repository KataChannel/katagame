### 4️⃣ PROVINCE UPGRADE SYSTEM - 3 DIMENSIONS (NEW)

```
EVERY PROVINCE HAS 3 UPGRADE TRACKS

Track 1: FARMER LEVEL (1-20)
├─ Increases: Population capacity, basic resource generation
├─ Bonus per level: +5% resource gen, +10 population
├─ Cost: Gold + Rice (increases per level)
├─ Synergy: Enables special buildings and features

Track 2: RESOURCE LEVEL (1-10)
├─ Specializes: One resource per province
├─ Bonus per level: +20% that resource, +10% synergy
├─ Cost: That resource + Wood
├─ Example: Hanoi → Focus on Gold Mining

Track 3: DEVELOPMENT LEVEL (1-15)
├─ Improves: Infrastructure, buildings, overall growth
├─ Bonus per level: +3% all resources, faster construction
├─ Cost: All resources combined
├─ Benefit: Unlocks advanced features per milestone
```

**Hidden Milestone System** (NEW):
- Level 5 Farmer: Passive +2% resources (permanent)
- Level 3 Resource: Synergy bonus activated
- Level 8 Resource: Active bonus (1x daily, ×2/×3/×5 for 1 hour)
- Level 5 Development: Infrastructure bonus (-10% construction time)
