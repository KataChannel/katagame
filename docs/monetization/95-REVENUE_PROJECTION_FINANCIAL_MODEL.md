## 🚨 RISK FACTORS & MITIGATION

### Risk 1: Lower Than Projected Conversion Rates
```
Risk: If conversion is 10% instead of 18% in Year 1
Impact: Revenue drops from 16.1B to 8.9B VND (-45%)
Mitigation:
├─ Improve onboarding experience
├─ Reduce friction in payment flow
├─ A/B test pricing
├─ Increase FOMO mechanics
└─ Extend sales funnel to later days
```

### Risk 2: High Churn Rate
```
Risk: If D30 retention is 15% instead of 20%
Impact: Monthly revenue decreases 25-30%
Mitigation:
├─ Implement robust progression system
├─ Add seasonal events every 2 weeks
├─ Daily login rewards (habit formation)
├─ Guild/social features (retention)
└─ Content roadmap (predictable updates)
```

### Risk 3: Market Competition
```
Risk: Similar game launches with better monetization
Impact: DAU growth slows from 8% to 3% monthly
Mitigation:
├─ Unique IP (Vietnam history/culture)
├─ Educational component (differentiator)
├─ Fast feature releases (stay ahead)
├─ Community engagement (loyalty)
└─ Esports positioning (engagement)
```

### Risk 4: Payment Processing Issues
```
Risk: Payment gateway failures or high fraud
Impact: Lost revenue + refund costs (5-10%)
Mitigation:
├─ Integrate multiple payment methods
├─ Fraud detection system
├─ Customer support (quick refunds)
├─ PCI compliance certification
└─ Regular security audits
```
