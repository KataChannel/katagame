### 2. ✅ 6 New Provinces (Total: 9 Provinces)
**Mô tả**: Expand playable area from 3 to 9 provinces  

**New Provinces Added**:
1. **Thái Bình** - Eastern coastal region
   - Fish farming specialization
   - Higher population growth
   - Unique buildings (Fishing boats)
   
2. **Hải Dương** - Northern coast
   - Rice production focus
   - Trade hub bonuses
   - Maritime units available
   
3. **Hà Giang** - Mountain region
   - Mining specialization (stone/ore)
   - Difficult terrain (slower production)
   - Elite mountain troops
   
4. **Tuyên Quang** - River valley
   - Water resources
   - Hydroelectric buildings
   - Strategic military position
   
5. **Lạng Sơn** - Border region
   - Defense focus
   - Border trading mechanics
   - Militia units
   
6. **Cao Bằng** - Far north
   - Rare resources
   - High difficulty
   - Prestige rewards (for completionists)

**Province Mechanics**:
```
Each province has:
├─ Unique visual theme
├─ Province-specific resources
├─ Regional building types
├─ Climate bonuses/penalties
├─ Strategic positioning
└─ Historical storyline (3-5 missions)
```

**Total Map Progression**:
```
MVP1: 3 provinces (basic)
MVP2: +6 provinces (9 total) - 70+ hours of content
MVP3: +54 provinces (63 total) - Complete Vietnam map
```

### 4. ✅ Gacha/Cosmetic Roll System (NEW!)
**Tên gọi**: "Hero Gacha" / "Legendary Summon"  
**Mô tả**: Randomized cosmetic draws (NO P2W mechanics)  

**Gacha Structure**:
```
┌────────────────────────────────────────────┐
│ SINGLE PULL: 49,900 VND                    │
├────────────────────────────────────────────┤
│ 1x random cosmetic item                    │
│ Common (60%), Rare (30%), Legendary (10%)  │
└────────────────────────────────────────────┘

┌────────────────────────────────────────────┐
│ 10x PULL: 490,000 VND (saves 9,900)        │
├────────────────────────────────────────────┤
│ 10x random cosmetics                       │
│ Guaranteed 1 Rare minimum                  │
│ Guaranteed 1 Legendary every 50 pulls      │
└────────────────────────────────────────────┘

┌────────────────────────────────────────────┐
│ PITY SYSTEM (Collection Mechanic):          │
├────────────────────────────────────────────┤
│ Pull 100 times = Guaranteed Legendary      │
│ Resets after getting Legendary             │
│ Shows "pulls until next legend" counter    │
└────────────────────────────────────────────┘
```

**Gacha Items** (Cosmetics Only):
- Hero skins (different outfits)
- Weapon skins (visual effects)
- Pet cosmetics (decorative pets)
- Emotes (animations)
- Building skins
- **NO stat bonuses, NO power increase**

**Gacha Collection Mechanics**:
```
Collect cosmetics → Unlock badges
         ↓
More cosmetics owned → Higher collection percentage
         ↓
Hit 50% collection → Bonus rewards
         ↓
Hit 100% collection → Ultimate cosmetics
```

**Expected Revenue (MVP2)**:
- 3-5% of DAU pull daily (gacha whales)
- Average spend: 150K/day per whale
- 100K DAU × 4% × 150K = 600M/month
- **~600M VND/month**
- **% of MVP2 revenue: ~20%**

### 6. ✅ Login Calendar System (NEW!)
**Tên gọi**: "Daily Login Rewards" / "28-Day Calendar"  
**Mô tả**: Rewards for logging in consistently  

**Login Calendar Format**:
```
┌───────────────────────────────────────────────────┐
│ 28-DAY LOGIN CALENDAR                             │
├───────────────────────────────────────────────────┤
│                                                   │
│ Day 1:   100 gems                                │
│ Day 2:   200 gold                                │
│ Day 3:   50,000 food                             │
│ Day 4:   500 gems                                │
│ Day 5:   Rare hero skin                          │
│ Day 6:   200,000 wood                            │
│ Day 7:   Free Premium Pass 24h (MAJOR!)          │
│ ...                                              │
│ Day 14:  2,000 gems                              │
│ Day 21:  Legendary hero skin                     │
│ Day 28:  5,000 gems + Title badge (ULTIMATE!)    │
│                                                   │
│ Resets monthly (new calendar each month)         │
│ Must login daily (missing 1 day = reset)         │
│ "X days in a row!" counter shows progress        │
└───────────────────────────────────────────────────┘
```

**Psychological Mechanics**:
- **Streak counter**: "10 days in a row!" (shows commitment)
- **Payoff dates**: Day 7 & 28 have MAJOR rewards
- **Daily habit**: Ensures daily login (DAU metrics)
- **Catch-up**: If miss a day, can "check-in" next day (not reset)

**Expected Revenue (MVP2)**:
- Drives DAU from 100K to 130K (+30%)
- Free Premium Pass Day 7 = upsell path
- Increased gem sales from habitual players
- **Indirect revenue: ~200M VND/month**
- **% of MVP2 revenue: ~5%**
