### 📱 3. MOBILE-FIRST REDESIGN (Ưu tiên cao!)

#### 🎨 Thiết Kế Mobile Mặc Định

**Nguyên tắc thiết kế:**
- ✅ Touch-first: Nút lớn, dễ bấm (min 48x48px)
- ✅ One-hand operation: Controls ở dưới cùng
- ✅ Vertical scrolling: Tối ưu cho scroll mobile
- ✅ Swipe gestures: Chuyển tabs, dismiss modals
- ✅ Bottom navigation: Tab bar cố định
- ✅ Card-based layout: Dễ scan và tương tác
- ✅ Minimal text: Icons + short labels
- ✅ Responsive breakpoints: 
  - Mobile: < 640px (mặc định)
  - Tablet: 640px - 1024px
  - Desktop: > 1024px (enhanced)

#### 🎯 Tối Ưu Hóa Mobile

**Layout Changes:**
```
Old (Desktop-first):        New (Mobile-first):
┌─────────────────┐        ┌───────────┐
│ Header (wide)   │        │  Header   │
├─────────────────┤        │ (compact) │
│ Nav (horizontal)│        ├───────────┤
├─────────────────┤        │           │
│                 │        │  Content  │
│    Content      │        │ (vertical)│
│   (2-3 cols)    │        │ (1 col)   │
│                 │        │           │
├─────────────────┤        ├───────────┤
│     Footer      │        │   Tab     │
└─────────────────┘        │    Bar    │
                           └───────────┘
```

**Component Redesigns:**

1. **Resource Bar**
   - Stack vertically on mobile
   - Swipeable carousel cho nhiều resources
   - Larger touch targets

2. **Province Cards**
   - Full-width cards
   - Collapse details by default
   - Tap to expand
   - Swipe to next province

3. **Navigation**
   - Bottom tab bar (iOS/Android style)
   - 5 main tabs visible
   - Settings in overflow menu
   - Icons + minimal text

4. **Combat UI**
   - Portrait mode default
   - Large hero cards
   - Swipe to use skills
   - Tap to target

5. **Modals & Dialogs**
   - Slide up from bottom
   - Full-screen on mobile
   - Easy dismiss gesture
   - Native feel

**Breakpoint Strategy:**
