# 🇻🇳 Đất Việt Truyền Thuyết - MVP 1

> **Game farming/strategy kết hợp văn hóa Việt Nam, có thể kiếm tiền ngay từ MVP đầu tiên**

## 🎯 Giới Thiệu MVP 1: "Khởi Nguồn Đất Việt"

MVP 1 là phiên bản đầu tiên của game "Đất Việt Truyền Thuyết" - một game farming/strategy độc đáo kết hợp giáo dục văn hóa Việt Nam.

### ✨ Tính Năng Chính

- **🗺️ 3 Tỉnh Đầu Tiên**: Hà Nội, Nghệ An, Quảng Ninh
- **🖱️ Click Farming**: Thu thập tài nguyên bằng cách click
- **👥 Hệ Thống Nông Dân**: Thuê nông dân tự động/thủ công
- **📚 Trung Tâm Văn Hóa**: Học lịch sử Việt Nam để nhận phần thưởng
- **👑 Premium Pass**: 3 gói đặc quyền (Basic/Premium/Royal)
- **🛒 Cửa Hàng**: Mua gói tài nguyên và power-ups
- **🎮 Game Loop**: Tự động tăng tài nguyên theo thời gian

### 🎮 Cách Chơi

1. **Thu thập tài nguyên**: Click vào các ô tài nguyên (Vàng, Lúa, Gỗ, Đá, Văn hóa)
2. **Thuê nông dân**: Tự động hóa việc thu thập
3. **Nâng cấp tỉnh**: Tăng hiệu suất sản xuất
4. **Mở khóa tỉnh mới**: Mở rộng đế chế với 200 vàng
5. **Học văn hóa**: Nhận điểm culture và học về Việt Nam
6. **Mua Premium Pass**: Tăng tốc phát triển với các đặc quyền

## 🛠️ Tech Stack

- **Frontend**: Next.js 15 + TypeScript + Tailwind CSS
- **State Management**: Zustand với Persist middleware
- **UI Components**: Lucide React icons + Framer Motion
- **Storage**: LocalStorage (sẽ nâng cấp lên database trong MVP 2)

## 🚀 Cài Đặt & Chạy

### Yêu Cầu Hệ Thống
- Node.js 18+ 
- NPM hoặc Yarn

### Các Bước Cài Đặt

```bash
# 1. Clone repository
git clone <repo-url>
cd katagame

# 2. Cài đặt dependencies
npm install

# 3. Chạy development server
npm run dev

# 4. Mở trình duyệt tại http://localhost:3000
```

### Scripts Có Sẵn

```bash
npm run dev      # Chạy development server với Turbopack
npm run build    # Build production với Turbopack
npm run start    # Chạy production server
```
