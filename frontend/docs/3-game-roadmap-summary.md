# Tóm Tắt Lộ Trình Game "Đất Việt Truyền Thuyết"

## 🎯 Ý Tưởng Cốt Lõi
Game farming/strategy kết hợp văn hóa Việt Nam, giáo dục lịch sử, có thể **kiếm tiền ngay từ MVP đầu tiên**.

## 🗺️ Concept Game
- **63 tỉnh thành Việt Nam** unlock theo thời gian
- **Hệ thống ngũ hành** tương sinh tương khắc
- **Heroes truyền thuyết**: Thánh Gióng, Sơn Tinh, Thủy Tinh, Mẫu Dất
- **Farming + khai thác + nuôi thú + thủ thành**
- **Giáo dục văn hóa** tích hợp trong gameplay

## 📅 4 MVP Kiếm Tiền Ngay

### MVP 1: "Khởi Nguồn Đất Việt" (Tháng 1-2)
- **3 tỉnh đầu**: Hà Nội, Nghệ An, Quảng Ninh
- **Core gameplay**: Click farming, auto-farmers, resource management
- **Monetization**: Premium Pass (50-100k/tháng), In-app purchases
- **Thu nhập**: **5-15 triệu/tháng**

### MVP 2: "Anh Hùng Truyền Thuyết" (Tháng 3-4)
- **Thêm 6 tỉnh**: Huế, Đà Nẵng, TP.HCM, Cần Thơ, Đà Lạt, Phú Quốc
- **Features**: Combat system, Pet system, Ngũ hành
- **Monetization**: Battle Pass (100k/season), Gacha system
- **Thu nhập**: **15-40 triệu/tháng**

### MVP 3: "Liên Minh Đất Việt" (Tháng 5-8)
- **Tất cả 63 tỉnh thành**
- **Features**: Multiplayer, Guild system, Trading, Events
- **Monetization**: Marketplace fee, Guild features, NFT
- **Thu nhập**: **50-150 triệu/tháng**

### MVP 4: "Đế Chế Đất Việt" (Tháng 9-12)
- **Features**: Dynasty system, Historical campaigns, Advanced economics
- **Monetization**: Esports, Content Creator Program, Brand partnerships
- **Thu nhập**: **100-500 triệu/tháng**

## 💰 Chiến Lược Monetization Tối Ưu

### Season 90 Ngày (Thay vì 365 ngày)
- **Tháng 1**: Launch hype → High spending
- **Tháng 2**: Mid-season events → Sustained engagement
- **Tháng 3**: Season finale → FOMO purchases

### Các Mô Hình Kiếm Tiền
1. **Subscription**: 99k-999k/tháng (3 tiers)
2. **Tiered Gacha**: 49k-499k/pull với pity system
3. **Virtual Real Estate**: 199k-50 triệu/plot
4. **Educational Premium**: 299k/season
5. **Corporate B2B**: 50k/student/năm
6. **Event-based**: 49k-499k entry fees

### Chiến Thuật FOMO
- Limited-time offers (24-48h)
- "Only 50 left" counters
- Seasonal exclusives never return
- Psychological pricing: 19k thay vì 20k

## 🛠️ Tech Stack Hiện Đại

### Frontend
- **Next.js 14** + TypeScript + Tailwind CSS
- **GraphQL Subscriptions** cho real-time
- **Zustand + React Query** cho state management

### Backend
- **NestJS** + GraphQL + Apollo Federation
- **PostgreSQL 15** với TypeORM + sharding
- **Redis Cluster** cho caching & sessions
- **MinIO** Object Storage cho assets
- **Bull Queue** với Redis cho background jobs

### Infrastructure
- **Docker + Docker Compose** deployment
- **3 NestJS instances** load balancing
- **PostgreSQL cluster**: Primary + 2 replicas
- **Redis cluster**: 3 nodes
- **MinIO distributed storage**
- **Prometheus + Grafana** monitoring
